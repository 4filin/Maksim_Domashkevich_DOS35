## Создание Virtual mashine (Linux) и установка правил соединения через SSH

     -  Создайте 2 виртаульных машины (далее - VM1, VM2. Вы можете дать любое удобное вам название). Используйте образ ubuntu24.10
     -  Пройдите польностью все этапы установки и вручную разбейте свободное пространство на диски.
     -  Настройте SSH-соеденение следующим образом: хостовая ОС -> VM1, VM1 -> хостовая ос, VM2 -> VM1, VM2 -x> хостовая ОС. Запрет соеденения можно осуществить любым удобной полиси через iptables.
     - с помощью инструмента Hashicorp Packer создайте образы двух виртуальных машин с заранее подготовленными предустановками, описанными выше. Должно быть 2 конфига.
  
1. Создание вручную было сделано и описано в *_Homework_Lesson_3_OS_P1_* поэтому пробую настройку и автоматическое создание
2. Устанавливаю Packer прописываем пути в PATH проверяем, что программа доступна 
    ![step1](./temp/step1.png)
3. Создаю две папки для конфигураций двух VM машин Ubuntu instance 1 и instance 2 
4. Создаю два файла meta_data c названием instance и user_data который содержит блок        настроек внутри виртуальной машины  имя юзера сетевые настройки, разбивка диск  и доступ через публичный ключ SSH.
5. Помещаю эти файлы в соответствующие папки для VM 1 и VM 2 
6. Создаю файлы _config_instans-vm1.pkr.hcl_ и _config_instans-vm1.pkr.hcl_ которые непосредственно и управляют процессом создания, на так называемом языке HCL (HashiCorp Configuration Language), где  на основе файлов блоков данных и файлов meta_data и user_data. 
    Файл сожержит в себе информацию: 
    - архитектура: размер диска, колиичество выделенной памяти, количество ядер и сетевая карта 
    - откуда брать установочный образ
    - откуда брать плагины для работы в нашем случае HyperV
    - пути к SSH 
    - также в него можно поместить блок команд которые будут выпоолнены для виртуальной машины после установки
7. Размещаю файлы и папки в директории _packer_ubuntu_   
       ![step2](./temp/step2.png)
       ![step2.1](./temp/step2.1.png)
8. Запускаю Терминал, перехожу в созданную папку и инициирую чтение содержимых файлов и конфигов и добавление плагина
